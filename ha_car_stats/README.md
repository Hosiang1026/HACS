# 汽车统计（ha_car_stats）

Home Assistant 自定义集成。本地统计油耗、费用、保养；可选扫码登录 12123，拉取车辆 / 驾驶证 / 违章；可选高德车机 GPS。当前版本 **1.1.1**，需 Home Assistant **2024.12.0+**。

一车一条配置，可反复添加。

## 功能

- 加油 / 费用 / 保养记录，计算油耗、月年费用、每公里成本、历年汇总
- 保养、保险、驾驶证到期前通知；每年 1 月 1 日发送上年用车汇总
- （可选）12123 App 扫码登录，15 分钟保活；失效后触发重新登录
- （可选）车辆：车牌、类型、状态
- （可选）驾驶证：车型、状态、剩余记分、清分日期、有效期
- （可选）违章监控（每日拉取），新增违章可通知
- （可选）高德车机 GPS：位置追踪、车速、导航、离家/到家通知

## 安装

将 `custom_components/ha_car_stats` 复制到 Home Assistant 的 `custom_components` 目录：

```bash
cd /config/custom_components
```

或 HACS：自定义存储库添加本仓库，类别选「集成」，下载后重启。

重启 HA，在「设置 → 设备与服务 → 添加集成」中搜索「汽车统计」。

## 添加车辆

1. 勾选「交管12123」和/或「高德车机GPS」（都不勾则仅本地统计）
2. 若 12123：选省份 → 用 12123 App 扫码 → 选车
3. 若高德：填抓包凭证 → 选车机 → 选车主 person、活跃轮询上限
4. 填写车辆信息
5. 配置通知（可选）

跳过 12123 时：不创建车牌 / 驾驶证 / 违章 / 会话 / 登录时间实体；通知项不含违章、驾驶证到期。

跳过高德时：不创建 GPS / 车机传感器；通知项不含离家、到家。可在选项中「绑定高德车机」后补上。

会话失效后：选项「车辆设置 → 12123 车辆 → 重新登录」扫码，或走集成的重新认证流程。「退出登录」清除会话并暂停拉取。

| 保养周期(公里) | 10000 | 保养公里目标 |
| 保养周期(天) | 365 | 保养周期 |
| 保险到期日 | 空 | 用于「保险剩余天数」 |
| 年检到期日 | 空 | 用于「年检剩余天数」 |
| 保养日期 | 空 | 上次保养日期 |
| 保养里程 | 0 | 上次保养时的里程 |
| 电池更换日期 | 空 | 用于「电池使用时间」 |
| 里程 | 0 | 可选手填；未选里程实体时写入本集成里程 |
| 油价 | 按油号 | 可选手填；未选油价实体时用此值（否则用内置默认） |

油价实体属性名支持：`92` / `92#` / `gas92` / `price_92` / `92号` / `92号汽油`（95、98 同理）。属性无匹配时再尝试读取实体 state。

| 活跃轮询上限(分) | 30 | 在线但未行驶时，随机 1～上限 分钟轮询 |

| 配置项 | 默认 | 说明 |
|---|---|---|
| 排除区域 | 空 | `zone`。车在区内时，车主靠近不加速轮询 |

| 家区域 | zone.home | `zone`，可多选；用于离家/到家与通勤终点 |

### 定位更新

「汽车定位时间」只在本次请求拿到该车有效坐标时更新。请求失败、没有坐标或会话失效时，沿用上一次时间。

启动后第一次拉取前，按活跃轮询上限等待（默认 30 分钟）。车主进入距车 300 米、或离开 300 米时立刻拉一次。车在排除区域内时，车主靠近不加快。车主离开排除区域且车机离线时也立刻拉一次。

之后按当前状态决定下一次：

| 状态 | 间隔 |
|---|---|
| 行驶中或导航中 | 5 分钟 |
| 车主在 300 米内，车不在排除区域，且尚未行驶 | 5 分钟，直到开始行驶或车主离开 |
| 车主已离开 300 米，车机仍在线且未行驶 | 5 分钟，直到离线 |
| 在线但停着，车主不在 300 米内 | 随机 1～活跃轮询上限 分钟（默认 30） |
| 离线或状态未知，车主不在 300 米内 | 随机 1～120 分钟 |
| 会话失效 | 停止拉取 |

定时拉取不会续期 `sessionid`。会话失效时发一次 HA 通知，需在「高德凭证」里重新填写。

车机抓包接口不需传车牌；逆地理编码不需传车牌；导航通勤算路有车牌时可选传入以提高过路费/限行准确性。

| 配置项 | 默认 | 说明 |
|---|---|---|

| 上年用车通知 | 开 | 仅每年 1 月 1 日 |
| 保养到期通知 | 关 | 需填写保养日期；剩余里程 ≤ 0 或剩余天数 ≤ 0 时通知 |

## 记录数据

面板：填「汽车里程」、「加油升数」或「加油金额」（缺一项按当前油价互算），可选填加油站，点「确认加油」。

或调用服务（多车时指定 `device_id` / `entry_id`）：

| 服务 | 说明 |
|---|---|
| `ha_car_stats.add_refuel` | `liters` / `cost` / `odometer` / `full`（默认加满）/ `station`。升数与金额可只填一项 |
| `ha_car_stats.add_expense` | `type`：`etc` / `park` / `insure` / `repair` / `other`；`amount` |
| `ha_car_stats.add_maintenance` | `odometer` / `type`（默认常规）/ `cost`。同步更新车辆信息中的保养日期与保养里程 |
| `ha_car_stats.set_odometer` | 更新当前里程（未配置外部里程实体时） |

## 计算规则

**平均油耗**：至少 2 条加满记录时，(末次加满里程 − 首次加满里程) 之间的加满升数 ÷ 里程差 × 100。否则为 0（未知）。

**油耗等级**：≤9 优秀，≤11 良好，≤13 正常，≤15 偏高，>15 费油，无数据为未知。

**本年总费用**：本年加油 + 本年费用 + 本年保养。

**每公里费用**：全部加油 + 费用 + 保养 ÷ 当前里程。

**保养剩余**：剩余里程 = 保养里程 + 周期公里 − 当前里程；剩余天数 = 保养日期 + 周期天 − 今天（独立计算）。

**保险/年检剩余**：到期日减今天的天数。

**使用时间**：购车日至今天的年数（÷ 365.25，一位小数）。

**电池使用时间**：电池更换日至今天的年数（÷ 365.25，一位小数）。

**历年统计**：跨年后结转上年费用与里程；通知仅 1 月 1 日发送。

**剩余记分**：`max(0, 12 − 累计记分)`。部分违章行为无官方记分时用内置对照表。

## 12123 接口

保活成功后再拉数据。车辆、驾驶证仅登录/重登或改车辆序号时拉取；违章每日一次；新增违章时再拉驾驶证。

失败指数退避，上限 2 小时；触发限流冷却 2 小时。会话失效（登录跳转 / 401 / 403）暂停接口并要求重新登录；其它 HTTP 错误仅重试保活。

## 通知内容

| 场景 | 标题 | 内容 |
|---|---|---|
| 新增违章 | `汽车违章通知` | 车牌、地点、行为、记分、罚款、时间 |
| 1 月 1 日 | `汽车上年用车通知` | 上年行驶里程、加油次数、油费、高速费、总费用 |
| 保养到期 | `汽车保养到期通知` | 剩余里程 ≤ 0 或剩余天数 ≤ 0 |
| 保险到期 | `汽车保险到期通知` | 到期日、剩余天数 |
| 年检到期 | `汽车年检到期通知` | 到期日、剩余天数 |
| 驾驶证到期 | `汽车驾驶证到期通知` | 车牌、到期日、剩余天数 |
| 离家 | `汽车离家通知` | 停车时长、当前位置、时间 |
| 到家 | `汽车到家通知` | 开车时长、当前位置、时间 |

保养 / 保险 / 年检 / 驾驶证同类通知每天最多一条。违章、驾驶证相关通知仅登录 12123 后生效。离家/到家仅绑定高德后生效。

上年用车：1 月 1 日 0/8/12/18 点检查；当天内 HA 重启也会检查。通知失败不推进年度结转起点，当天可重试。不跨日补发。
