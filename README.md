# Home Assistant 插件集

本文档介绍HACS自定义插件。

---

## 通知管理（ha_msg_notify）

统一管理通知渠道与消息轮播。全屋添加一次，是否推送由各自动化决定，本集成负责渠道配置、发送与轮播。

### 功能

- 九种渠道：企业微信 / 钉钉 / 飞书 / SMTP / REST / Shell / HA notify / 语音播报 / 屏幕显示
- 渠道增删改、独立开关；企微等自动注册为 `notify.{渠道ID}`
- 消息轮播队列（Store 持久化，不受 255 字符限制）
- 服务：`send` / `carousel` / `clear` / `remove`

### 场景

- 多通道告警（企微 + 邮件 + TTS）
- 仪表盘消息轮播展示
- 与通勤、天气、节日等集成配合统一发送

---

## 通知消息轮播卡片（ha_msg_notify_card）

Lovelace 前端卡片，配合 `ha_msg_notify` 使用。

### 功能

- 固定高度展示消息队列
- 文字自下而上滚动，全文显示后轮播下一条
- 新消息入队立即切到最新

### 场景

- 看板 / 平板常亮显示最新通知
- 家庭大厅信息条

---

## 音乐播放器（ha_music_player）

本地音乐播放后端；卡片 `ha-music-player-card` 需单独安装。

### 功能

- 扫描 HA 主机音乐目录（mp3 / flac / m4a / wav / ogg / aac / wma）
- `media_player`：播放控制、进度、音量、循环、随机、浏览曲库
- 输出：浏览器、其他音箱、可选小爱
- 读取标签、封面、内嵌/旁路歌词

### 场景

- NAS / 本地曲库在 HA 内播放
- 推送到客厅音箱或小爱
- Lovelace 音乐控制面板

## 智能场景（ha_iot_scene）

用「场景 + 多规则」配置家电联动：触发 → 条件 → 控制 → 按需播报（不发 notify）。

### 功能

- 触发：状态变化 / 数值高于 / 数值低于 / 定时
- 最多 3 个条件（AND / OR），星期、时间窗、延迟、冷却
- 动作：开/关/切换、窗帘、仅播报
- 成功/失败播报；场景总开关与最近执行记录

### 场景

- 工作日定时开帘
- 门口有人多条件联动灯/播报
- 温湿度超限关窗帘、电量低提醒

## 综合资讯（ha_general_info）

聚合彩票、金银价、新闻、股票、影视音乐，支持通知与语音播报。

### 功能

- 福利彩票：双色球 / 3D / 快乐8 / 七乐彩，预测与开奖前推送
- 金银价格：国内外金银、金店/银行金价、三金估算、历史低价
- 新闻 RSS、自选股、豆瓣/网易云热榜
- 服务：`refresh`、`clear_gold_low`

### 场景

- 早间资讯与金价播报
- 双色球开奖日提醒
- 自选股交易时段盯盘

## 中国节日（ha_chinese_festival）

节日 / 节气 / 纪念日 / 生日 / 证件到期汇总，支持黄历、AI 运势、定时通知与语音 Intent。

### 功能

- 公历/农历节日、节气、国际日、法定假日（放假/补班/高速免费）
- 生日、纪念日、证件临期；三伏 / 四九 / 梅雨
- 黄历宜忌、八字、月相；假期规划与日历点选
- 分类定时 notify；可选 AI 运势、高级通知规则

### 场景

- 每日日历/黄历播报
- 生日与证件到期提醒
- 法定假日与拼假规划
- 语音助手查询下一节日

## 天气预报（ha_weather_forecast）

多城市天气实况与预报，支持预警/降雨通知与播报；内置 Lovelace 卡片。

### 功能

- 数据源：中国天气网 / 和风 / 彩云；多城市
- `weather` + 气温/体感/湿度/AQI/风力/生活指数/预警
- 高峰时段加频刷新；预警与降雨通知
- 卡片 `custom:weather-forecast-card`（安装即可用）
- 兼容 `ha_msg_notify` 轮播

### 场景

- 多地天气看板
- 降雨/预警推送与 TTS
- 早晚高峰通勤气象关注

## 汽车统计（ha_car_stats）

本地油耗/费用/保养统计；可选交管 12123、高德车机 GPS。一车一条配置。

### 功能

- 加油 / 费用 / 保养记录；油耗、月年费用、每公里成本、历年汇总
- 保养、保险、年检、驾驶证到期通知；元旦上年用车汇总
- 可选 12123：车辆、驾驶证、违章监控
- 可选高德车机：位置、车速、导航、离家/到家

### 场景

- 家用车油耗与费用账本
- 违章与证件到期提醒
- 车机定位与通勤导航信息

---

## 燃油价格（ha_fuel_price）

抓取各省 92/95/98 汽油与 0 号柴油价，记录历史最低，支持定时与接近最低价通知。全屋配置一次。

### 功能

- 31 省/直辖市油价；按调价日自动排程抓取
- 每省当前价、历史最低、加油费用估算
- 全局调价趋势；定时摘要通知；95 号接近最低价通知

### 场景

- 盯本地油价择机加油
- 与 `ha_car_stats` 油价实体联动
- 周末油价摘要推送

## 通勤统计（ha_commute_stats）

按人员位置统计在家 / 公司 / 外地 / 外出，支持离家通知、站点通知、上班打卡与工时薪酬。

### 功能

- 家/公司区域匹配；经纬度判断外地；外出人数推算
- 可选室内人数传感器覆盖在家人数
- 到家/离家/进站/出站通知（可限时段）
- 上班打卡、工时/加班/调休/月薪
- 高德逆地理与路径规划写回通勤实体

### 场景

- 家人到家/离家推送
- 地铁站点进出提醒
- 弹性工时与加班薪酬统计
- 与 `ha_msg_notify` 统一推送

## 用电统计（ha_energy_stats）

监听电量实体增量，按本年阶梯与峰谷/统一单价累计日/月/年电量电费。每个电量实体一条配置。

### 功能

- Wh / MWh 自动换算 kWh；峰谷或统一单价
- 三档阶梯；日/月/年峰谷电量与电费
- 每日附加电量；日/月/年历史
- 结算通知（日结算可设电费阈值）

### 场景

- 峰谷电价家庭电费估算
- 阶梯用电告警与月结推送
- 多电表分别统计

## iCloud 中国（ha_icloud_cn）

面向大陆的 iCloud 查找集成，访问 `icloud.com.cn`，定位 iPhone / iPad / Mac / Watch（不支持 AirTag）。

### 功能

- 每台设备：位置、电量、步数、状态、地址、通勤距离/时间
- 播放声音、发送消息、丢失模式
- 按在家/本地/出远门与高峰低谷动态轮询
- 可选高德通勤；与官方 `icloud` 勿同账号并用

### 场景

- 大陆环境查找家人设备
- 丢手机响铃 / 丢失模式
- 通勤距离与位置地址看板

---

## 小米云服务（ha_xiaomi_cloud）

通过小米云「查找设备」获取账号下多台手机的定位、状态与控制。

### 功能

- 一账号自动发现多台设备，动态创建实体
- 周期性查找：GPS（GCJ-02）、电量、在线状态
- 定位设置：平时/高峰/低谷间隔；电量低于 10% 且不在家/公司时自动减缓
- 高德设置：逆地理、通勤距离/时间/路况
- 按钮：更新、播放声音、查找、丢失模式；文本：联系电话、丢失留言、云剪贴板

### 场景

- 安卓/小米手机家庭定位
- 丢手机响铃与丢失模式
- 通勤地址与路况看板
