# 通勤统计 (ha_commute_stats)

Home Assistant 自定义集成（v1.1.0，需 HA ≥ 2024.1.0）：按人员位置统计在家 / 公司 / 外地 / 外出，支持离家通知、站点通知、上班打卡与工时薪酬。

全屋只添加一次；选项里可增减人员，并按人编辑家庭设置 / 公司设置。

## 功能

- 按 `person` 状态匹配家区域 / 公司区域
- 按经纬度判断本地范围外（外地）
- 外出人数 = `|总人数 − 在家 − 外地 − 公司|`
- 配置室内人数传感器时，覆盖在家人数（可多选，数值求和）
- 进出家区域自动切换离家标记并触发到家 / 离家通知（受时段限制）
- 进出站点区域可分别通知（进站区域进入、出站区域离开）
- 可选上班统计：进出公司区域打卡、工时 / 加班 / 调休 / 月薪
- 高德 Key：到家 / 离家 / 站点 / 上下班通知时逆地理与路径规划，结果可写回位置 / 通勤实体

## 生成实体

### 全屋

| 实体 ID | 说明 |
| --- | --- |
| `sensor.people_home_count` | 在家人数 |
| `sensor.people_comp_count` | 公司人数 |
| `sensor.people_waidi_count` | 外地人数（≥0） |
| `sensor.people_out_count` | 外出人数 |

### 每人（名称取自配置的人员名称 slug）

| 条件 | 实体 | 说明 |
| --- | --- | --- |
| 有人员实体 | `sensor.{名称}_activity` | 活动：`home` / `company` / `out` / `away` |
| 有家区域 | `switch.{名称}_home` | 离家标记 |
| 有家区域 | `sensor.{名称}_home_duration` | 当日在家时长（小时，每日 0 点重置） |

### 每人（启用上班统计且配置了公司区域）

| 实体 | 说明 |
| --- | --- |
| `switch.{名称}_work` | 上班标记（可手动开关） |
| `sensor.{名称}_work_duration` | 工作时长（扣除午休） |
| `sensor.{名称}_work_time` | 上班时长（≤ 标准工时） |
| `sensor.{名称}_over_time` | 加班时长 |
| `sensor.{名称}_work_state` | 状态：`holiday` / `rest` / `off_work` / `lunch` / `overtime` / `working` |
| `number.{名称}_comp_time` | 调休时长 |
| `number.{名称}_month_salary` | 月薪累计 |
| `datetime.{名称}_work_start_time` | 上班开始时间 |
| `datetime.{名称}_work_end_time` | 下班结束时间 |

## 配置

### 全局

| 项 | 说明 |
| --- | --- |
| 总人数 | 用于计算外出人数 |
| 室内人数传感器 | 可选，覆盖在家人数 |
| 通知动作 | 到家 / 离家 / 站点 / 上下班通知 |
| 播报设备 | 可选，语音播报 |
| 高德 Key | 逆地理与路径 |

### 人员

| 项 | 说明 |
| --- | --- |
| 名称、人员实体 | 必填 |
| 活动状态实体 | 可选，影响通勤骑车 / 驾车模式 |
| 位置 / 通勤信息 / 通勤距离 / 通勤时间 | 可选，通知时由高德写回 |

### 家庭设置（每人独立）

家区域、本地城市范围、回家 / 离家通知与时段、进站 / 出站通知与区域。

### 工时与薪酬（每人独立）

公司区域、启用上班统计、标准工时、午休、加班起算、上下班打卡时段、日薪、加班 / 节假时薪、今日类型（状态为 `holiday` / `节假日`）、调休起算加班与扣除、每日重置时刻、每月重置日、上班通知。

### 选项菜单

全局设置、家庭设置、公司设置、添加人员、编辑人员、删除人员。

## 计算规则

1. **在家**：`person` 状态匹配任一家区域；有室内人数传感器时改用其值。
2. **公司**：状态匹配任一公司区域。
3. **外地**：坐标在本地框外；`外地人数 = max(0, 框外人数 − 公司人数)`。
4. **外出**：`|总人数 − 在家 − 外地 − 公司|`。
5. **活动状态**：家 → 公司 → 外地 → 外出（优先级依次）。
6. **离家标记**：离开家区域 → 开；进入 → 关。
7. **在家时长**：在家累计秒数 / 3600；每日 0 点重置，重置时若仍在家则继续计。
8. **上班**：在上班打卡时段进入公司 → 上班；在下班打卡时段离开公司 → 下班；时段外短暂离开不下班；手动关上班标记会结算。
9. **工时**：上班起止之间扣除午休重叠；加班 = max(0, 工时 − 标准工时)。
10. **调休**：当日加班 > 调休起算阈值时，累加 `加班 − 调休扣除`（每日最多一次）。
11. **月薪**：非节假日 `日薪 + 加班 × 加班时薪`；节假日 `工时 × 节假时薪`（每日最多一次）。
12. **跨日重置**：到每日重置时刻若仍在上班，先结算再续计；到每月重置日清零调休与月薪。

## 高德调用

仅通知触发时请求。坐标 WGS84 → GCJ02。

- 逆地理 1 次
- 未在家且距家 ≥400m 时再路径规划；通勤模式：活动状态为在家/公司 → 骑车，外出/外地 → 驾车；无活动实体时距家 >10km 驾车，否则骑车
- 位移 <400m 走缓存

## 安装

复制到 `custom_components/ha_commute_stats`，或通过 HACS 安装。重启后在「设置 → 设备与服务」添加。
