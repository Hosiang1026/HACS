# ha_honor_cloud

> Home Assistant 自定义集成，通过 Playwright 后端同步荣耀账号下设备的定位、状态与控制（响铃、丢失模式），并支持高德逆地理与通勤信息。

要求 Home Assistant **2024.7.0** 及以上，以及可访问的 Playwright 后端服务。

## 功能概览

- 一个荣耀账号自动发现**多台设备**，动态创建实体
- 周期性向 Playwright 后端同步位置、电量、在线状态
- 可选**主动定位**（触发荣耀云实时定位）
- 集成级 **定位设置**（更新间隔、主动定位；电量 ≤10% 自动减缓定位）
- 集成级 **高德设置**（逆地理编码、通勤距离/时间/路况）
- 每台设备提供 **按钮**（响铃、丢失模式）与 **文本**（锁屏密码、联系电话、丢失留言）
- 会话保活与登录冷却，认证暂态期间保留缓存位置
- 选项分菜单保存，定位 / 高德 / 账号配置互不影响

## 安装

### HACS（推荐）

1. 安装 [HACS](https://hacs.xyz/)
2. HACS → 集成 → 右上角 ⋮ → **自定义仓库**
3. 添加本仓库地址，类别选 **Integration**
4. 搜索 **ha_honor_cloud** 并安装
5. 重启 Home Assistant

### 手动安装

1. 下载最新版本
2. 将仓库内容复制到 Home Assistant 的 `custom_components/ha_honor_cloud`
3. 重启 Home Assistant

## 配置

### 添加集成

1. **设置 → 设备与服务 → 添加集成**
2. 搜索 **ha_honor_cloud**
3. 填写 Playwright 服务地址、荣耀账号与密码
4. 首次登录约 30–60 秒；完成前会显示初始化通知，设备实体在数据返回后自动出现

### 选项菜单

集成卡片 → **配置**，进入选项菜单：

- **定位设置**：更新间隔、主动定位
- **高德设置**：Key、家区域、通勤、活动状态
- **账号与后端**：服务地址、账号密码、API Key

保存任一菜单后集成会自动 reload 使新配置生效。

### 选项：定位设置

| 选项 | 说明 | 默认 |
|------|------|------|
| 位置更新间隔 | 平时轮询间隔（分钟），范围 1–180 | 3 |
| 启用主动定位 | 轮询时触发荣耀云实时定位 | 开 |

> 任一设备电量 ≤10% 时，定位间隔自动变为平时间隔的 2 倍（无单独配置项）。

### 选项：高德设置

| 选项 | 说明 |
|------|------|
| 是否启用高德调用 | 开启地址解析与通勤相关调用 |
| 高德 Key | [高德开放平台](https://lbs.amap.com/) Web 服务 Key（密码框） |
| 每日调用上限 | 建议免费额度 ≤4500，默认 4500 |
| 是否启用通勤 | 需同时开启高德、填写 Key，并至少选择一个家区域 |
| 家区域 | 选择一个或多个 `zone` 实体作为「家」 |
| 活动状态 | 可多选；值 `在家`/`公司` → 骑行，`外出`/`外地` → 驾车 |

未匹配活动状态时：距家不足 10 公里按骑行，否则按驾车。人在家区域内时通勤距离为 0。  
未填 Key 时：地址传感器、通勤相关传感器不会更新（定位追踪仍正常）。

### 选项：账号与后端

| 选项 | 说明 |
|------|------|
| Playwright 服务地址 | 后端地址，以 `http://` 或 `https://` 开头 |
| 荣耀账号 / 密码 | 可修改登录凭据 |
| 后端 API Key | 请求头 `X-API-Key`，后端启用鉴权时填写 |

### 配置持久化

- 首次添加集成时写入默认选项
- **定位设置**、**高德设置**、**账号与后端**分开保存，互不影响
- 保存时合并已有配置，不会覆盖另一菜单的选项
- 高德 Key 留空表示保留已保存的 Key
- 读取优先级：`options` → `data` → 内置默认值

## 坐标系

设备追踪器主坐标为 **WGS84**；属性中同时提供 **GCJ-02** 坐标与地址字段，供高德相关能力使用。

## 实体说明

集成会创建一个 Hub 设备（`荣耀云服务`），并为账号下**每台手机**创建一个设备条目。

### Hub 实体

| 实体 ID 建议名 | 类型 | 说明 |
|----------------|------|------|
| `ha_honor_cloud_created_at` | 传感器 | 集成创建时间 |
| `ha_honor_cloud_locate_count` | 传感器 | 当日定位 API 调用次数 |
| `ha_honor_cloud_amap_count` | 传感器 | 当日高德 API 调用次数 |
| `ha_honor_cloud_status` | 传感器 | 服务状态 |
| `button.ha_honor_cloud_update` | 按钮 | 立即主动定位并刷新 |

### 每台设备实体（动态创建）

| 建议实体 ID 后缀 | 类型 | 说明 |
|------------------|------|------|
| （设备 slug） | 设备追踪 | GPS 经纬度（WGS84）、精度、电量；属性含 GCJ-02 与地址 |
| `_battery` | 传感器 | 电量 % |
| `_phone_status` | 传感器 | 在线 / 离线 / 未知 |
| `_update_time` | 传感器 | 最后定位时间 |
| `_address` | 传感器 | 高德逆地理地址（需 Key） |
| `_commute_distance` | 传感器 | 到家/离家通勤距离 km |
| `_commute_time` | 传感器 | 预计通勤时间（分钟） |
| `_commute_info` | 传感器 | 路况/路线摘要 |
| `_ring` / 响铃 | 按钮 | 响铃找手机（共享设备不创建） |
| 丢失模式 | 按钮 | 开启丢失模式（需先填文本实体；共享设备不创建） |
| `_lost_password` | 文本 | 锁屏密码（4–16 位数字） |
| `_lost_message` | 文本 | 丢失模式锁屏留言 |
| `_lost_number` | 文本 | 丢失模式联系电话 |

设备追踪属性还包括：`device_id`、`last_update`、`gcj02_lat`、`gcj02_lng`、`address` 等。

## 服务

域：`ha_honor_cloud`

### `ha_honor_cloud.force_sync`

立即同步。`mode`：`normal`（缓存定位，默认）、`active`（实时定位，60 秒限频）。

```yaml
service: ha_honor_cloud.force_sync
data:
  mode: active
```

### `ha_honor_cloud.force_locate`

对全部设备执行主动定位并刷新实体。

```yaml
service: ha_honor_cloud.force_locate
```

### `ha_honor_cloud.ring`

响铃。`device_id` 必填（设备追踪器属性中的设备 ID），`action` 默认 `start`。同一设备 30 秒内只能触发一次。

```yaml
service: ha_honor_cloud.ring
data:
  device_id: "设备ID"
  action: start
```

### `ha_honor_cloud.lost`

丢失模式。`device_id` 必填，`action` 为 `start` 或 `stop`。`password`、`message`、`phone` 可省略，省略时使用该设备文本实体中的值。锁屏密码为 4–16 位数字；设备已有锁屏密码时可留空。

```yaml
service: ha_honor_cloud.lost
data:
  device_id: "设备ID"
  action: start
  phone: "13800138000"
  message: "捡到手机请联系我"
```

## 工作原理

1. 插件按配置间隔请求后端 `/sync`
2. 开启「主动定位」时，同步会触发荣耀实时定位并轮询结果；仅真正拿到新坐标才计入每日定位次数
3. 若配置了高德 Key，则进行逆地理编码；启用通勤时计算到家路线
4. 认证暂态期间保留上次位置并重试；恢复后立刻再定位一次
5. 新设备首次出现在账号下时，自动追加对应实体

### 会话保活与登录

1. 日常优先使用本地 cookie，并由后端约每 20 分钟 heartbeat 刷新 CSRF，不频繁重登
2. 接口鉴权失败时，先 bootstrap 刷新 token；仍失败才触发浏览器重登
3. 全浏览器重登有 10 分钟冷却；仅本地无会话文件时允许跳过冷却做首次登录
4. 重登过程中若已有设备缓存，返回缓存位置并标记认证暂态
5. 重登成功后自动补一次主动定位

## 后端接口

集成只与 Playwright 服务通信，不直接登录荣耀云。

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/status` | 连通性与会话状态 |
| POST | `/auth/ensure` | 下发凭据 / 触发登录 |
| POST | `/sync` | 拉取设备与位置（可 `force_locate`） |
| POST | `/locate` | 主动定位 |
| POST | `/ring` | 响铃 |
| POST | `/lost` | 丢失模式 |

请求体含 `session_key`。配置了 API Key 时附带请求头 `X-API-Key`。  
同步在认证暂态时可能返回缓存设备，并带 `auth_pending`；登录成功后后端会标记下次同步补主动定位。

## 常见问题

**Q：添加集成时报无法连接 Playwright**  
A：确认服务地址以 `http://` 或 `https://` 开头，且 Home Assistant 能访问该地址。

**Q：有 device_tracker 但没有 address**  
A：在「高德设置」中启用高德调用并填写 Key；通勤功能还需启用并选择家区域。

**Q：丢失模式按钮无效**  
A：先在对应设备的锁屏密码、丢失留言、联系电话文本实体中填写内容，再按丢失模式按钮。

**Q：主动定位不生效 / 次数不增加**  
A：确认已开启「主动定位」；仅真正拿到新坐标才计入每日定位次数；手动主动定位有约 60 秒限流。

**Q：实体短暂不更新但位置还在**  
A：多为认证暂态（重登中）。集成会保留缓存位置并自动重试，登录成功后会补一次主动定位。
