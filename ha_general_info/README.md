# 综合资讯 (ha_general_info)

Home Assistant 自定义集成，聚合福利彩票、金银价格、新闻、股票、影视音乐等资讯，支持通知与语音播报。

- 版本：`1.0.0`
- Domain：`ha_general_info`
- 数据方式：云端轮询 (`cloud_polling`)

> 天气预报已拆至独立集成 `ha_weather_forecast`。

## 功能模块

| 模块 | 默认 | 数据源 | 说明 |
|------|------|--------|------|
| 福利彩票 | 开 | 中国福利彩票 (cwl) | 双色球 / 福彩3D / 快乐8 / 七乐彩；双色球频率预测与开奖前推送 |
| 金银价格 | 开 | 黄金价格网 | 国内金银、国际金银、金店/银行金价、三金估算、金银历史低价 |
| 新闻 | 开 | RSS | 可配置多个 RSS |
| 股票 | 关 | 新浪 / 腾讯 | 自选股；可仅交易时段刷新 |
| 影视音乐 | 关 | 豆瓣热榜 + 网易云 | 电影 / 剧集 / 音乐热榜；含上映/开播/发行时间 |

## 安装

将 `ha_general_info` 放到 `config/custom_components/ha_general_info/`，重启 Home Assistant。

## 配置

设置 → 设备与服务 → 添加集成 → **综合资讯**

选项中可分别配置：全局通知、彩票、金银、新闻、股票、影视音乐。

### 福利彩票

- 开奖日 21:10–22:30 自动加频
- 开启「双色球预测」后仅预测双色球；开奖窗口内、结果未出前推送一次预测
- 推送需开启该模块的「模块通知」

### 金银价格

- 品种：黄金 / 白银 / 金店均价 / 银行金价（属性含各店、各行明细）
- 国际金/银价（USD/oz）
- 三金估算：金店均价×克重、黄金价×克重（项链/手镯/戒指可配）
- 黄金/白银历史低价（可关）

## 服务

| 服务 | 说明 |
|------|------|
| `ha_general_info.refresh` | 刷新；`module`: `all` / `lottery` / `metal` / `news` / `stock` / `media` |
| `ha_general_info.clear_gold_low` | 清除金银历史低价记录 |
