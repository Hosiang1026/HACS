# 智能场景（ha_iot_scene）

Home Assistant 自定义集成。用「场景 + 多规则」配置家电联动：触发 → 条件 → 控制被控端 → 按需播报。不发通知。当前版本 **1.2.0**。

一个配置条目 = 一个场景名，场景内可挂多条规则。

## 功能

- 触发类型：状态变化 / 数值高于 / 数值低于 / **定时触发**
- 最多 3 个条件实体，逻辑可选 **AND / OR**
- 可选星期、时间窗、延迟、冷却
- 动作：打开 / 关闭 / 切换 / 开窗帘 / 关窗帘 / 仅播报
- 成功/失败播报分别勾选启用；执行后等待可配置秒数再检查状态（默认 3 秒）
- 播报设备：`text` / `input_text` / `media_player`（优先 `xiaomi_miot.intelligent_speaker`，否则 `tts.speak`）
- 场景总开关；记录最近规则、播报、时间、规则数量

## 安装

将本目录复制到 Home Assistant：

```text
/config/custom_components/ha_iot_scene/
```

或 HACS：自定义存储库添加本仓库，类别选「集成」，下载后重启。

重启后：「设置 → 设备与服务 → 添加集成」搜索「智能场景」。

## 添加场景

1. 填写场景名称、播报设备
2. 添加至少一条规则
3. 可继续「再加一条规则」或「完成创建」
4. 之后在选项中：基本设置 / 添加规则 / 编辑规则 / 删除规则

## 配置项

### 场景

| 配置项 | 说明 |
|---|---|
| 场景名称 | 显示名，并用于实体 ID 前缀（中文名无法 slug 时用 `scene_` + entry_id 前 8 位） |
| 播报设备 | 可多选 `media_player` / `text` / `input_text` |

### 规则

| 配置项 | 默认 | 说明 |
|---|---|---|
| 规则名称 | 规则 | 便于识别 |
| 启用规则 | 开 | 单条规则开关 |
| 触发类型 | 状态变化 | `state` / `numeric_above` / `numeric_below` / `time` |
| 控制端实体 | 空 | 非定时触发时必填 |
| 变为状态 | 空 | `state`：新状态 |
| 来自状态 | 空 | `state`：旧状态 |
| 数值阈值 | 0 | 数值高于/低于；越过阈值才触发 |
| 定时时刻 | 空 | `time` 触发时使用，如 `07:30:00` |
| 星期 | 空 | 可多选；空=每天；定时与实体触发均可限制 |
| 条件逻辑 | AND | 多个条件之间 `and` / `or` |
| 条件1~3 实体/状态 | 空 | 最多 3 组；状态空则仅要求实体存在 |
| 时间窗起 / 止 | 空 | 额外时间过滤；可只填一侧；跨夜支持 |
| 被控制实体 | 空 | 可多选 |
| 控制动作 | 打开 | 见下表；`none` 只走播报逻辑 |
| 启用成功播报 | 关 | 勾选且文案非空才播 |
| 成功播报文案 | 空 | |
| 启用失败播报 | 关 | 勾选且文案非空才播 |
| 失败播报文案 | 空 | |
| 冷却秒数 | 30 | `0` 不限制 |
| 执行前延迟 | 0 | 匹配后、执行动作前等待 |
| 状态检查等待 | 3 | 执行后等待再检查被控状态，再决定成功/失败播报；`0` 立即检查 |

### 控制动作

| 动作 | 行为 |
|---|---|
| `turn_on` | 打开（cover 为开帘；vacuum 为开始清扫） |
| `turn_off` | 关闭（cover 为关帘；vacuum 为回充） |
| `toggle` | 切换 |
| `open` | `cover.open_cover` |
| `close` | `cover.close_cover` |
| `none` | 不调用服务 |

### 执行逻辑

1. 场景启用
2. 规则启用
3. 触发匹配（实体变化 / 数值跨越 / 到点）
4. 星期、条件（AND/OR）、时间窗通过
5. 未在冷却期
6. 延迟后执行被控动作
7. 再等待「状态检查等待」秒数，核对被控是否达到目标状态（`unavailable`/`unknown` 算失败）
8. 按成功/失败开关决定是否播报
9. 更新最近规则 / 文案 / 时间

## 生成实体

| 实体 | 说明 |
|---|---|
| `switch.<场景>_enabled` | 场景启用 |
| `sensor.<场景>_last_rule` | 最近规则名 |
| `sensor.<场景>_last_message` | 最近文案（无文案时为「成功」/「失败」） |
| `sensor.<场景>_last_time` | 最近执行时间 |
| `sensor.<场景>_rule_count` | 规则数量 |

## 配置示例

### 定时开帘（工作日 07:30）

| 项 | 值 |
|---|---|
| 触发类型 | `time` |
| 定时时刻 | `07:30:00` |
| 星期 | mon–fri |
| 条件1 | 窗帘实体 / `closed`（可选） |
| 被控 | 客厅窗帘 |
| 动作 | `open` |

### 门口有人（多条件 OR）

| 项 | 值 |
|---|---|
| 触发 | 人数 `numeric_above` 0 |
| 条件逻辑 | `or` |
| 条件1 | 门口人体 = `on` |
| 条件2 | 门口灯 = `on` |
| 成功播报 | 勾选，文案「主人 门外有人活动」 |

### 监控联动 / 温度关帘 / 电量低

仍用状态或数值触发 + 条件/时间窗，同前。

## 当前限制

- 条件最多 3 组
- 窗帘等慢设备若检查等待过短，可能误判失败（可加大等待秒数）
- 不发送 notify 通知
- 冷却仅内存，重启清零
