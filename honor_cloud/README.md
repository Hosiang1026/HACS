# 荣耀云服务

Home Assistant 自定义集成，通过 Playwright 后端同步荣耀账号下的设备位置，并提供电量、地址、响铃、丢失模式与通勤信息。

要求 Home Assistant **2026.9.0** 及以上，以及可访问的 Playwright 后端服务。

## 安装

### 安装参数（添加集成时）

| 参数 | 说明 |
| --- | --- |
| Playwright 服务地址 | 后端根 URL，须 `http://` 或 `https://` |
| 荣耀账号 | 后端用于登录荣耀云 |
| 荣耀密码 | 对应密码 |

添加集成时会请求 `/status` 与 `/auth/ensure` 校验连通性与凭据。

将本目录复制到：

```
config/custom_components/honor_cloud/
```

重启 Home Assistant。设置 → 设备与服务 → 添加集成 → 搜索「荣耀云服务」。

也可通过 HACS 以自定义仓库添加（仓库根目录即集成）。

## 配置

添加集成时填写：

| 项 | 说明 |
| --- | --- |
| Playwright 服务地址 | 后端地址，以 `http://` 或 `https://` 开头 |
| 荣耀账号 | 荣耀云账号 |
| 荣耀密码 | 荣耀云密码 |

首次登录约 30–60 秒。完成前界面会显示初始化通知，设备实体在数据返回后自动出现。

### 选项

设置 → 荣耀云服务 → 配置：

**定位设置**

- 平时刷新间隔：1–180 分钟，默认 10 分钟
- 高峰时段 ×3：默认 07:00–09:00、17:00–20:00 / 10 分钟
- 低谷时段 ×2：默认 20:00–00:00 / 60 分钟
- 仅工作日：高峰/低谷是否只在周一至周五生效（默认开）

定位间隔优先级：

1. **全部设备**都在已配置的家区域或公司区域内：**10–120 分钟**取随机值（进入停留后固定，离开后下次再随机）
2. 离开家/公司后：高峰用高峰间隔，低谷用低谷间隔，其余用平时刷新间隔
3. 任一设备电量低于 **10%** 且不在家/公司时：固定 **60 分钟**

在家或公司（活动状态为「在家」「公司」，或位于已配置的家/公司区域）时不受低电量减缓影响。未配置家区域且未配置公司区域时不做停留随机间隔判断。当前已处于停留模式时，设备需超出区域半径 500 米才视为离开。已保存的平时刷新间隔不会自动改成 10。

**高德设置**

- 高德 Key、每日调用上限（默认 4500）
- 启用高德调用：地址解析与通勤路径
- 是否启用通勤：需同时开启高德、填写 Key，并至少选择一个家区域
- 家区域：Home Assistant `zone` 实体
- 公司区域：Home Assistant `zone` 实体（用于家/公司停留随机间隔）
- 活动状态：可多选。状态为「在家」「公司」时按骑行规划，「外出」「外地」时按驾车规划。未匹配时，距家不足 10 公里按骑行，否则按驾车。人在家区域内时通勤距离为 0

**账号与后端**

- 可修改服务地址、账号、密码
- 后端 API Key：请求头 `X-API-Key`，后端启用鉴权时填写

## 工作流程

### 会话保活与登录

1. 日常优先使用本地 cookie，并由后端约每 20 分钟 heartbeat 刷新 CSRF，不频繁重登。
2. 接口鉴权失败时，先 bootstrap 刷新 token；仍失败才触发浏览器重登。
3. 全浏览器重登有 10 分钟冷却，降低风控与验证码风险；仅本地无会话文件时允许跳过冷却做首次登录。
4. 重登过程中若已有设备缓存，后端与插件会返回缓存位置，实体保持可用，并标记认证暂态。
5. 重登成功后自动补一次主动定位。

### 定位更新

1. 插件按当前时段规则主动定位（家/公司区域 10–120 分钟随机；离开后按高峰/低谷/平时间隔；低电量固定 60 分钟）。
2. 拿到新坐标则立即更新实体并计入每日定位次数；未拿到则先用缓存，并在下次间隔前持续跟进，成功再更新，截止仍失败则保持缓存。
3. 认证暂态期间：保留上次位置，插件约每 15 秒重试（最多约 2 分钟）；恢复后立刻再定位一次。
4. 手动点击「更新」或调用主动定位服务：立即主动定位（后端约 60 秒限流）。

## 实体

每个设备：

| 类型 | 实体 |
| --- | --- |
| 设备追踪器 | 位置（WGS84；属性含 GCJ-02 坐标与地址） |
| 传感器 | 地址、更新时间、电量、手机状态、通勤距离、通勤时间、通勤信息 |
| 按钮 | 响铃、丢失模式（共享设备不创建） |
| 文本 | 锁屏密码、丢失留言、联系电话（共享设备不创建） |

集成级传感器：服务状态、创建时间、每日定位调用次数、每日高德调用次数。

集成级按钮：更新。

## 服务

`honor_cloud.force_sync`  
立即同步。`mode`：`normal`（缓存定位，默认）、`active`（实时定位，60 秒限频）。

`honor_cloud.force_locate`  
对全部设备执行主动定位并刷新实体。

`honor_cloud.ring`  
响铃。`device_id` 必填（设备追踪器属性中的设备 ID），`action` 默认 `start`。同一设备 30 秒内只能触发一次。

`honor_cloud.lost`  
丢失模式。`device_id` 必填，`action` 为 `start` 或 `stop`。`password`、`message`、`phone` 可省略，省略时使用该设备文本实体中的值。锁屏密码为 4–16 位数字；设备已有锁屏密码时可留空。

## 后端接口

集成只与 Playwright 服务通信，不直接登录荣耀云。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/status` | 连通性与会话状态 |
| POST | `/auth/ensure` | 下发凭据 / 触发登录 |
| POST | `/sync` | 拉取设备与位置（可 `force_locate`） |
| POST | `/locate` | 主动定位 |
| POST | `/ring` | 响铃 |
| POST | `/lost` | 丢失模式 |

请求体含 `session_key`。配置了 API Key 时附带请求头 `X-API-Key`。

同步在认证暂态时可能返回缓存设备，并带 `auth_pending`；登录成功后后端会标记下次同步补主动定位。

## 卸载

设置 → 设备与服务 → 荣耀云服务 → 配置条目 → 删除。删除后重启 Home Assistant 可确保服务与实体完全移除。

## 自动化

本集成**不提供**专用 trigger / condition 平台。请使用状态传感器、设备追踪器与 `honor_cloud.*` 服务编写自动化。
