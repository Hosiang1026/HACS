# 燃油价格 (ha_fuel_price)

Home Assistant 自定义集成（v1.0.0，需 HA ≥ 2024.1.0）：抓取各省/直辖市 92/95/98 汽油与 0 号柴油价格，本地记录历史最低价，并支持定时通知与接近最低价通知。

全屋只配置一次；选项里可增减省份。删除省份会清理对应设备与实体。

## 功能

- 从 [汽油价格网](http://m.qiyoujiage.com) 抓取油价：有效调价日 → 该日 00:15 定点抓；文案无日期 → 每天 00:15；过期或距今超 60 天 → 不排程
- 支持 31 个省/直辖市（下拉选择，禁止手填错误编码）
- 每省独立设备：当前油价 + 历史最低价 + 最低油价日期 + 加油费用（加油升数 > 0 时）
- 全局设备：创建时间、更新时间、调价趋势、手动更新按钮
- 全局定时通知：可开/关，按「每天 / 周末」勾选，调用所选通知动作
- 省份「发送最低油价通知」：95 号现价接近历史最低时推送（使用该省自己的通知动作，独立于全局定时开关）

## 生成实体

### 全局

| 实体 ID | 说明 |
| --- | --- |
| `sensor.fuel_price_created_time` | 集成创建时间 |
| `sensor.fuel_price_update_time` | 最近一次成功抓取时间 |
| `sensor.fuel_price_trend` | 调价趋势（状态最长 255 字，完整文案见属性 `full_text`） |
| `button.fuel_price_manual_update` | 手动立即抓取油价 |

### 每省（`{code}` 为省份编码，如 `zhejiang`；含 `-` 时改为 `_`，如 `shanxi_3`）

| 实体 ID | 单位 | 说明 |
| --- | --- | --- |
| `sensor.{code}_fuel_price_92` | CNY/L | 92 号汽油 |
| `sensor.{code}_fuel_price_95` | CNY/L | 95 号汽油 |
| `sensor.{code}_fuel_price_98` | CNY/L | 98 号汽油 |
| `sensor.{code}_fuel_price_0` | CNY/L | 0 号柴油 |
| `sensor.{code}_fuel_price_low_date` | date | 最低油价日期（任一油品刷新最低价时更新） |
| `sensor.{code}_fuel_price_92_low` | CNY/L | 92 号最低油价 |
| `sensor.{code}_fuel_price_95_low` | CNY/L | 95 号最低油价 |
| `sensor.{code}_fuel_price_98_low` | CNY/L | 98 号最低油价 |
| `sensor.{code}_fuel_price_0_low` | CNY/L | 0 号最低油价 |
| `sensor.{code}_fuel_price_92_cost` | CNY | 92 号加油费用（升数 × 油价） |
| `sensor.{code}_fuel_price_95_cost` | CNY | 95 号加油费用 |
| `sensor.{code}_fuel_price_98_cost` | CNY | 98 号加油费用 |
| `sensor.{code}_fuel_price_0_cost` | CNY | 0 号加油费用 |

加油费用实体仅在全局「加油升数」> 0 时生成；设为 0 后 reload 会清理对应实体。

属性：

- 当前油价：`province`、`fuel_type`、`update_time`
- 最低油价：`province`、`fuel_type`、`low_date`
- 最低油价日期：`province`、`low_92` / `low_95` / `low_98` / `low_0`
- 加油费用：`province`、`fuel_type`、`fill_liters`、`unit_price`

## 配置

### 安装时

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 名称 | 集成标题 | 燃油价格 |
| 省份 | 下拉选择 | — |
| 发送最低油价通知 | 该省接近最低价时推送 | 关 |
| 发送通知动作 | 该省接近最低价时调用的 `notify.*`，可多选 | 空 |

### 选项菜单

#### 全局设置

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 加油升数 | 用于计算加油费用，范围 0–200；为 0 时不生成费用实体 | 60 |
| 开启发送通知 | 定时油价摘要通知总开关 | 开 |
| 每天发送 | 勾选后每天发送（优先于周末） | 关 |
| 周末发送 | 仅勾选此项且未勾选每天时，仅周六日发送 | 开 |
| 发送通知动作 | 定时摘要用的 `notify.*` 服务，可多选 | 空 |

说明：

- 抓取后按趋势文案重排下次抓取：`M月D日24时` → 次日 00:15；`M月D日零时` → 当日 00:15；仅有「下次调价M月D日」→ 按 24 时惯例取次日；无日期 → 每天 00:15；日期已过期或距今超 60 天（文案未更新）→ 取消定时、不每天抓；集成加载时也会抓一次；也可按 `button.fuel_price_manual_update` 立即抓
- 定时通知在每次成功抓取后判断；同一天最多发一次；需已配置全局通知动作
- 通知日期会持久化，重启不会同日重复推送

#### 添加 / 编辑 / 删除省份

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 省份 | 下拉选择 | — |
| 发送最低油价通知 | 95 号现价 − 历史最低 ≤ 0.1 元时通知 | 关 |
| 发送通知动作 | 该省接近最低价时调用的 `notify.*`，可多选 | 空 |

接近最低价通知：

- 使用该省「发送通知动作」（不用全局动作）
- 不依赖「开启发送通知」
- 每省每天最多一次
- 首次写入该省 95 号最低价时不通知（避免初始化误报）

## 支持的省份

北京、天津、上海、重庆、河北、山西、辽宁、吉林、黑龙江、江苏、浙江、安徽、福建、江西、山东、河南、湖北、湖南、广东、广西、海南、四川、贵州、云南、西藏、陕西、甘肃、青海、宁夏、新疆、内蒙古。

## 安装

1. 将 `ha_fuel_price` 目录复制到 Home Assistant 的 `custom_components/ha_fuel_price`
2. 或通过 HACS「自定义仓库」添加本仓库后安装
3. 重启 Home Assistant
4. 在「设置 → 设备与服务」中添加「燃油价格」

依赖：`beautifulsoup4`（安装集成时由 HA 自动安装）。

## 数据来源

- 省份油价：`http://m.qiyoujiage.com/{province_code}.shtml`
- 调价趋势：`http://m.qiyoujiage.com`

单省抓取失败不影响其它省份；全部失败时实体进入不可用状态。历史最低价保存在 HA 本地 Store，仅在刷新出更低价格时更新。
