# 用电统计（ha_energy_stats）

Home Assistant 自定义集成，监听电量实体增量，按本年阶梯电价累计日 / 月 / 年电量与电费。计电可选峰谷或统一单价。当前版本 **1.0.0**，要求 HA ≥ 2024.1.0。

每个电量实体一条配置，不可重复添加。

## 功能

- 监听 `energy` 电量传感器增量，Wh / MWh 自动换算成 kWh
- 计电模式：峰谷电计电 / 统一单价
- 按时段拆高峰 / 低谷；按本年累计电量分三档电价
- 日、月、年分别累计峰谷电量和电费
- 可选每日附加电量，按高峰时长比例拆入峰谷
- 内部用高精度累加，电量 / 电费展示保留 2 位小数
- 保留本结算月每日历史、本年各月历史、历年汇总
- 日 / 月 / 年结算时可发通知
- 首次添加可填入现有本月 / 本年累计

## 安装

将 `ha_energy_stats` 复制到 Home Assistant 的 `custom_components` 目录：

```bash
cd /config/custom_components
# 本仓库根目录下的 ha_energy_stats
```

或 HACS：自定义存储库添加本仓库，类别选「集成」，下载后重启。

重启 HA，在「设置 → 设备与服务 → 添加集成」中搜索「用电统计」。

## 配置项

### 电表与时段

| 配置项 | 默认 | 说明 |
|---|---|---|
| 名称 | — | 设备名 |
| 电量实体 | — | `sensor`，`device_class=energy` |
| 高峰开始 / 结束 | 08:00 / 22:00 | 开始 ≤ 结束：区间内为高峰；开始 > 结束：跨夜高峰 |
| 每日结算 | 00:00 | 日累计清零时刻 |
| 每日附加电量 | 0 kWh | 每天额外计入，0–100 |
| 每月结算日 | 1 | 1–28，该日把上月写入月历史 |

### 计电模式

添加时先选模式，再填对应电价。选项页可改模式，两套电价都会保留。

| 模式 | 说明 |
|---|---|
| 峰谷电计电（默认） | 高峰 / 低谷各用一档电价 |
| 统一单价 | 三档各一个电价，峰谷用量仍按时段拆，计价不分峰谷 |

### 阶梯电价

按**本年累计电量**分档：

| 配置项 | 默认 |
|---|---|
| 一档上限 | 2760 kWh |
| 二档上限 | 4800 kWh |
| 一 / 二 / 三档峰电价 | 0.568 / 0.618 / 0.868 ¥/kWh |
| 一 / 二 / 三档谷电价 | 0.288 / 0.338 / 0.588 ¥/kWh |
| 一 / 二 / 三档电价 | 0.538 / 0.588 / 0.838 ¥/kWh |

### 电费通知

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用通知 | 关 | 结算时发送 |
| 通知动作 | 空 | `notify.xxx`，可多选 |
| 日电费通知阈值 | 5 ¥ | 仅日结算且电费大于该值才通知 |

### 初始累计

仅首次添加时填写，没有则保持 0。写入后由本地存储继续累加。

## 计算规则

**增量**：电量实体数值上升才计入；下降视为电表回零，只更新基准、不加量。单位为 Wh 时 ÷1000，MWh 时 ×1000。

**峰谷**：当前时刻在高峰窗口内计入高峰，否则计入低谷。默认 08:00 ≤ t < 22:00 为高峰。统一单价模式同样按此时段拆用量。

**每日附加电量**：大于 0 时每天只加一次。高峰部分 = 附加 × 高峰秒数 / 86400，其余进低谷，再按当前阶梯计价并计入日 / 月 / 年。

**阶梯**：`本年高峰 + 本年低谷` ≤ 一档上限 → 1 档；≤ 二档上限 → 2 档；否则 3 档。一笔增量若跨档，按各档剩余额度拆开计价。

**电费**：峰谷模式 = 该档峰或谷电价 × 本次增量；统一单价 = 该档统一电价 × 本次增量。日 / 月 / 年同步累加。

**实时电价**：峰谷模式按当前时段取峰或谷电价；统一单价时峰 / 谷 / 实时电价均为当前阶梯统一电价。

**日结算**：到达「每日结算」时刻，或跨日后补结。昨日写入日历史，日累计清零，再加当日附加电量。日历史只保留当前结算月。

**月结算**：日历月变化时先暂存上月，日历史去掉该月。到达「每月结算日」（跨年也结）再写入本年月历史并通知。月历史只保留当前结算年，展示含当月。

**年结算**：年份变化。上年写入年历史；月历史清空。若结算月已跨到新年，本年累计先扣掉当月再入账，当月转入新年累计；否则年累计清零。

## 通知

仅开启「启用通知」且配置了通知动作时发送。

| 时机 | 条件 |
|---|---|
| 日结算 | 当日电费 > 日电费通知阈值 |
| 月结算 | 暂存月写入历史时 |
| 年结算 | 始终 |

内容：高峰 / 低谷 / 总计电量、应付电费、结算时间。
